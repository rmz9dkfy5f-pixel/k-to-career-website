# K to Career Website

This repository contains the public-facing K to Career website.

## Current Production Direction

`main` is the production branch. As of `v1.3.0`, the v3 site has been promoted to the repository
root.

## Design Reference Branches

Earlier design directions are preserved as branches, not production folders:

- `style/v1-reference`
- `style/v2-reference`

Do not merge these branches into `main` unless the project intentionally chooses to revive that
style direction.

## Development Workflow

Use short-lived branches for future changes and keep edits small, reviewable, and validated before
merging.

See `docs/workflow/branching-model.md` and `docs/workflow/claude-code-workflow.md`.
