## Canonical source

Release notes for this project are the versioned sections of the root **`CHANGELOG.md`**. The
policy in `docs/Standards/version_number_system.md` makes those sections the release notes; a
separate file would fragment release history across three places.

The release checklist itself is `docs/governance/RELEASE_GATE.md`.
